企鹅工坊 v1.6.2 更新说明
========================

发布日期：2026年1月25日

【新功能】
• 新增 Grok 视频生成服务 (grok-video-3)
  - 支持文本生成视频
  - 支持参考图片生成视频（最多1张）
  - 支持宽高比设置：3:2 / 2:3 / 1:1
  - 支持分辨率选择：720P / 1080P

• 首页设置新增 Grok 视频 API 配置
  - 可配置 API Key 和 Base URL
  - 与 Sora、Veo 视频服务并列

【优化】
• 画布视频节点新增 Grok 服务选项
• 视频节点异常状态显示优化
• 增强视频下载流程的日志输出

【已知问题修复】
• 修复视频服务类型切换时的 TypeScript 类型错误
